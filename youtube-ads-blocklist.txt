# =============================================================================
#  Pi-hole blocklist: YouTube / Google video ads
# =============================================================================
#  Author:   Russell Collis
#  Version:  1.0.0
#  Updated:  2026-11-22
#  Format:   one domain per line (Pi-hole "domains" format). Lines that start
#            with "#" are comments, and Pi-hole skips them.
#
#  ---------------------------------------------------------------------------
#  READ THIS FIRST: what DNS blocking can and can't do for YouTube
#  ---------------------------------------------------------------------------
#  Pi-hole works at the DNS level, so it can only block a whole hostname.
#  YouTube serves most of its video ads (the pre-roll and mid-roll clips) from
#  the SAME hosts as the real videos (*.googlevideo.com and www.youtube.com).
#  Pi-hole can't tell those requests apart, so it can't stop most in-video
#  ads without also breaking YouTube.
#
#  What this list DOES block:
#    - Ad banners and display ads on youtube.com and other sites
#    - Ad tracking and measurement beacons (impressions, clicks, conversions)
#    - The DoubleClick / AdSense / Ad Manager networks that YouTube embeds and
#      many third-party sites use
#    - Some ads on smart TV and console YouTube apps that still call these hosts
#
#  What this list CAN'T block:
#    - Most in-video ads in the YouTube app or website (same hosts as video)
#    - Sponsor segments read by creators (they're part of the video)
#
#  For in-video ads you need something that filters by URL path rather than
#  by domain: uBlock Origin (browser), SmartTube (Android TV), or YouTube
#  Premium.
#
#  ---------------------------------------------------------------------------
#  Domains this list leaves out on purpose (blocking them breaks YouTube)
#  ---------------------------------------------------------------------------
#    *.googlevideo.com / r*---sn-*.googlevideo.com
#        Lists that block these "ad server" hosts are a common myth. Those hosts
#        are YouTube's video CDN nodes. Blocking them causes buffering and
#        black screens and doesn't reliably stop ads.
#    s.youtube.com          playback stats; blocking it breaks watch history
#    youtubei.googleapis.com  the YouTube app's main API
#    jnn-pa.googleapis.com  playback attestation; blocking it breaks playback
#    i.ytimg.com / yt3.ggpht.com  thumbnails and channel avatars
#    googletagmanager.com   breaks login and checkout on many websites
#
#  ---------------------------------------------------------------------------
#  Known side effects of THIS list
#  ---------------------------------------------------------------------------
#    - Clicking "Sponsored" results at the top of Google Search won't work,
#      because those links go through googleadservices.com / doubleclick.net.
#      Scroll down to the normal result instead.
#    - Some shopping and price-comparison links that use ad redirects fail.
#    - imasdk.googleapis.com: some news and TV sites won't play their own
#      videos until their ad loads. If a site's video player breaks, allow this
#      domain in Pi-hole. (Mostly this just skips their ads.)
# =============================================================================
